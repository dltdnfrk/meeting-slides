The island is 902.4px wide inside a 635px flex container and is centred, so it
overflows BOTH edges: glyphs are cut at x<0 on the left and the row runs under
the transcript pane on the right. `flex: none` + the default `min-width: auto`
prevent it from ever shrinking, so the ellipsis .island__text already declares
can never engage.

NOTE: the independent review attributed V1 to a missing grid placement on a
direct child of #document-surface. The runtime parent chain above disproves
that: #island is a FLEX child of #stage-pane. The repair therefore targets the
measured flex-shrink failure, not the hypothesised grid placement.
